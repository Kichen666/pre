# Portfolio Compass

本地运行的可视化投资数据看板（仅本机使用），界面为白底蓝色调（Local Terminal 风格），支持下拉刷新与涨红跌绿：

- **首页概览**：当日上证、深证、创业板、科创板、北证50 指数行情；有色商品涨跌热力图（方块热力图：铜/铝/锌/铅/镍/锡/金/银/工业硅/碳酸锂主力合约，涨红跌绿，块大小=成交量）；IC / IM / IF / IH 股指期货当月年化升贴水率及当月每日走势。
- **持仓分析**：录入或上传四列数据「策略名称、金额、买入净值、当前净值」，自动生成持仓分布饼图（按当前市值占比）、盈利/亏损分布饼图，并可一键生成量化私募投资分析报告（本机量化分析引擎，含组合概览、盈亏结构、集中度、风险提示与管理建议）；数据保存在浏览器 localStorage。
- **策略分析**：上传「日期、净值」两列的 Excel（可多份），计算 **总收益、年化收益、夏普比率、卡玛比率、最大回撤**，多份数据自动计算**相关系数矩阵**；图表可自定义名称；数据保存在浏览器 localStorage。

## 运行

```bat
:: 方式一：双击 start.bat（首次会自动创建 conda 环境并安装依赖）
:: 方式二：手动
conda create -n pc310 python=3.10 -y
conda run -n pc310 python -m pip install -r requirements.txt
conda run -n pc310 python server.py
```

浏览器打开 <http://127.0.0.1:8321>：先进入视频背景的前置主页（标题/副标题居右 + “开始体验”按钮），点击进入看板（<http://127.0.0.1:8321/board>）。

> 说明：akshare 依赖 curl_cffi，不支持 Python 3.7/3.8，因此使用 conda 的 Python 3.10 环境。
> 不自动打开浏览器时，设置环境变量 `PC_NO_BROWSER=1` 后启动。

## 数据说明

- 行情与升贴水数据全部来自 **akshare**（东方财富 / 新浪财经），点击「数据刷新」会重新抓取。
- 任何接口没有返回的字段一律显示为 **—（null）**，**不编造、不填充**模拟数据。
- 升贴水率口径：`年化升贴水率 = (当月合约收盘价 / 现货指数收盘价 − 1) × 365 ÷ 距离最后交易日的自然日数`；当月合约每个交易日按当时可交易的最近月份合约计算（当月合约到期后切换到下月合约）。
- 若数据服务未启动，首页会显示浏览器中保存的上一次行情缓存。

## 上传格式

Excel 文件必须且只能有两列（第一行为表头）：

| 日期 | 净值 |
| ---- | ---- |
| 2024-01-02 | 1.0000 |
| 2024-01-03 | 1.0052 |

- 表头支持：`日期 / date`、`净值 / nav`（大小写不限）。
- 日期支持：`2024-01-02`、`2024/1/2`、`2024年1月2日`、`20240102`、Excel 日期单元格等。
- 格式不对（列数不符、表头缺失、日期 / 净值无效）会明确报错提示。

（持仓分析为四列格式，如下）

| 策略名称 | 金额 | 买入净值 | 当前净值 |
| ---- | ---- | ---- | ---- |
| 量化多策略A | 500000 | 1.0000 | 1.1630 |
| CTA趋势B | 200000 | 3.5000 | 3.2800 |

盈亏口径：份额 = 金额 ÷ 买入净值；当前市值 = 份额 × 当前净值；浮动盈亏 = 当前市值 − 金额。

`examples/` 目录提供了示例文件（净值格式 `sample_strategy.xlsx`、持仓四列格式 `sample_positions.xlsx`、错误格式 `sample_wrong.xlsx`）可测试。

## 接口（本机）

- `GET /api/market` —— 五大指数当日行情（失败字段为 null）
- `GET /api/commodities` —— 有色商品主力连续合约最新收盘价、涨跌幅、成交量（失败字段为 null）
- `GET /api/basis` —— IC/IM/IF/IH 当月年化升贴水率 + 当月逐日序列（失败字段为 null）

商品热力图口径：新浪主力连续合约（如 CU0）最近两个交易日收盘价计算涨跌幅，块大小为该日成交量（手）；无数据品种显示 NULL。

## 指标口径

- 年化收益：`(1 + 总收益)^(252 / 收益期数) - 1`
- 夏普比率：`(日收益均值 - 无风险利率/252) / 日收益标准差 × √252`，无风险利率按年化 3% 计
- 卡玛比率：`年化收益 / |最大回撤|`
- 最大回撤：`max(1 - 当日净值 / 截至当日最高净值)`
- 相关系数：多个净值序列按共同交易日对齐后，日收益率的皮尔逊相关系数
